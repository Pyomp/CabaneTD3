# CabaneTD3 portfolio deployment (frontend only)

Deploy the CabaneTD3 web project (`portfolio/` in this workspace) as a portfolio site, frontend only — no API backend.

## Steps

- [ ] Confirm `portfolio/` is the right project (has `e2e`, Playwright, Vite — check `portfolio/README.md` for what it actually is)
- [ ] Remove or mock any API calls so no backend endpoint is exposed
- [ ] `npm run build` in `portfolio/` and check the output in `dist/`
- [ ] Pick a static host (Vercel, Netlify, or GitHub Pages)
- [ ] Set any env vars the build needs for static assets
- [ ] Deploy and verify the live site
- [ ] Update the portfolio link wherever it's listed (resume, LinkedIn, personal site)
